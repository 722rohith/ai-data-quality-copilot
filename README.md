# AI Data Quality Copilot

An AI-powered data quality profiling and root-cause analysis copilot built with Streamlit, pandas, and Google Gemini API.

## Features
- Automated data quality profiling and health checks.
- Interactive AI chat assistant powered by Google Gemini for debugging data issues and SQL queries.
- Clean and intuitive Streamlit web interface.

## Tech Stack
- Python
- Streamlit
- Pandas
- Google Gemini API
